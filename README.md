# استودیوی تدریس — Smart Teach Studio

یک استودیوی کامل برای ساخت درس‌های تعاملی فارسی: بدون پاورپوینت، بدون سرور،
و **کاملاً آفلاین**. همه‌چیز در مرورگر ذخیره می‌شود و با یک `Ctrl/Cmd + K`
یا چند کلید میان‌بر می‌توان کل ارائه را ساخت، چید و اجرا کرد.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc -b && vite build
npm run preview
npm run lint
```

---

## چه چیزی هست

### ۱. کادرها (بلوک‌ها) با عرض انتخابی

ده نوع کادر: **متن، فهرست، فرمول، کادر رنگی، تلهٔ امتحانی، تصویر، ویدیو، کد،
پرسش، انیمیشن**.

هر کادر می‌تواند **تمام‌عرض**، **نصف‌عرض** یا **یک‌سوم** باشد. چیدمان روی یک
شبکهٔ شش‌ستونی انجام می‌شود، پس دو کادر کوتاه کنار هم می‌نشینند و صفحه شبیه
یک جزوهٔ چاپی می‌شود، نه یک ستون کارت‌های یکسان. انتخاب عرض با یک دکمه، با
کشیدن، یا از منوی هر کادر انجام می‌شود.

متن از نشانه‌گذاری سبک پشتیبانی می‌کند:

| نشانه | نتیجه |
| --- | --- |
| `**پررنگ**` | پررنگ |
| `*مورب*` | مورب |
| `` `کد` `` | تک‌کد |
| `==هایلایت==` | هایلایت |
| `$x = v_0 t + \tfrac12 a t^2$` | فرمول KaTeX |
| `https://…` | پیوند خودکار |

### ۲. بانک سؤال

پرسش‌ها با یک **مسیر برچسب سلسله‌مراتبی** شناخته می‌شوند:

```
کنکور:حرکت شناسی:حرکت شتابدار:نمودار سرعت-زمان
```

هرجا در یادداشت بخواهید پرسشی بگذارید:

* `Ctrl/Cmd + Shift + Q` — جست‌وجو و درج
* دکمهٔ «از بانک سؤال» روی نوار افزودن کادر یا داخل ویرایشگر پرسش
* `/bank` — صفحهٔ کامل بانک با درخت برچسب، فیلتر سختی/سال/ستاره و ورود-خروج JSON

جست‌وجو هم صورت سؤال و هم مسیر برچسب، منبع و سال را می‌گردد. اگر چیزی پیدا
نشد، می‌توانید همان‌جا با همان برچسب‌ها سؤال تازه بسازید و بلافاصله درج کنید.

کادرِ درج‌شده یک **پیوند زنده** به بانک دارد: صورت سؤال و گزینه‌ها داخل خودِ
ارائه هم ذخیره می‌شوند (پس اگر بانک را پاک کردید، کادر از کار نمی‌افتد) و اگر
سؤال را در بانک ویرایش کنید، کادر می‌تواند به نسخهٔ زنده وصل شود.

### ۳. کادر انیمیشن و استودیوی آن

هر کادر انیمیشن یک **صحنه** است که در `/studio/...` ساخته می‌شود:

* **کی‌فریم** روی پنج ویژگی (`x`, `y`, `size`, `rotation`, `opacity`) با پنج
  نوع درون‌یابی (خطی، نرم، تدریجی، توقفی، پله‌ای). خط زمان قابل کشیدن است و
  کی‌فریم‌ها را می‌شود با ماوس یا کلیدهای جهت‌دار جابه‌جا کرد.
* **نمودارهای متحرک** — هر منحنی یک فرمول در متغیر `t` است. چهار سبک رسم
  (خط ممتد، خط‌چین، نقطه‌ای، ناحیه) و «رسم تدریجی» با زمان.
* **فرمول‌نویسی امن** — یک زبان کوچک با `+ - * / ^ ()`، توابع
  (`sin cos tan sqrt abs exp ln atan2 …`) و ثابت‌ها. بدون `eval`؛ به یک درخت
  بسته کامپایل می‌شود، پس فرمول کاربر هیچ‌وقت به globalهای صفحه دست نمی‌رسد.
* **حرکت اجسام** — سه حالت: کی‌فریم دستی، فرمول (`x(t)`, `y(t)`)، یا
  «روی نمودار» که جسم روی منحنیِ در حال رسم سوار می‌شود.
* **بردار سرعت و شتاب** با محاسبهٔ عددی مشتق، ردِ حرکت، و جدول مقدارهای
  زندهٔ `x`, `y`, `vx`, `vy`, `|v|`, `ax`.
* یازده الگوی آماده: سرعت-زمان، مکان-زمان، نقطه روی نمودار، پرتابه، نوسان
  ساده، نمودار حرکتی، پرتاب توپ، نوسان گلوگاهی، کی‌فریم دستی و …
* **قاب‌بندی خودکار** — دامنهٔ محورها را از روی داده‌ها حدس می‌زند.

محورها روی مبدأ واقعی رسم می‌شوند، نه در حاشیهٔ کادر — چون «محور شناور»
دقیقاً همان سوءتفاهمی است که این ابزار برای رفعش ساخته شده.

### ۴. کاملاً با کلید

هر کاری بدون ماوس انجام می‌شود. `?` فهرست زندهٔ کلیدهای میان‌بر را باز
می‌کند؛ این فهرست از همان رجیستری میان‌برها خوانده می‌شود، پس هیچ‌وقت
کهنه نمی‌شود.

| | |
| --- | --- |
| `Ctrl/⌘ + K` | جعبه‌فرمان |
| `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` | واگرد / ازنو |
| `Ctrl/⌘ + Shift + Q` | درج پرسش از بانک |
| `Ctrl/⌘ + B` | بانک سؤال |
| `Ctrl/⌘ + Enter` | اجرای ارائه |
| `Ctrl/⌘ + Shift + A` | استودیوی انیمیشن |
| `Ctrl/⌘ + Shift + N` | بخش تازه |
| `?` | کلیدهای میان‌بر |

در **حالت اجرا**: `Space`/`←` گام بعد · `→` گام قبل · `G` نمای کل ·
`B` صفحهٔ سیاه · `N` یادداشت معلم · `T` تایمر · `D` حالت تیره · `F` تمام‌صفحه ·
`+`/`−` بزرگ‌نمایی · `۱`–`۴` یا `A`–`D` پاسخ به پرسش تازه‌نما.

در **استودیو**: `Space` پخش/مکث · `←`/`→` جابه‌جایی زمان · `,`/`.` پرش بین
کی‌فریم‌ها · `K` ثبت کی‌فریم در لحظهٔ فعلی · `Delete` حذف کی‌فریم ·
`1`…`9` انتخاب جسم.

### ۵. کشیدن و رها کردن

ترتیب بخش‌ها و ترتیب کادرها با ماوس کشیده می‌شود. همان کار با کلید هم می‌شود:
روی دستگیره فوکوس کنید، `Space` را بزنید تا بلند شود، با جهت‌ها جابه‌جا کنید
و دوباره `Space` بزنید تا بیفتد (یا `Esc` برای انصراف). جابه‌جایی‌ها با
صفحه‌خوان هم اعلام می‌شوند.

## معماری

```
src/
  types.ts                 مدل دامنه — کادرها، انیمیشن، بانک سؤال
  storage.ts               محل ذخیره + مهاجرت نسخهٔ ۱ → ۲
  docs/authoring.md        قالب JSON ارائه برای ساخت با هوش مصنوعی
  docs/api.md              مرجع کامل: میدان‌ها، مقادیر، اعتبارسنجی، خطاها
  sample.ts                ارائه و بانک سؤال نمونه
  lib/
    utils.ts               cn، اعداد فارسی، تاریخ، آرایه، BIDI
    hotkeys.ts             رجیستری میان‌بر + قفل کردن رویداد برای ظرف‌ها
    store.ts               انبار بیرونی سبک برای ارائه‌ها و بانک
    anim/expr.ts           کامپایلر امن فرمول (بدون eval)
    anim/engine.ts         کی‌فریم، درون‌یابی، مشتق، تیک محور، قاب‌بندی
    anim/presets.ts        یازده الگوی حرکت‌شناسی
  components/
    ui/                    دکمه، میدان، منو، مودال، جعبه‌فرمان، راهنمای کلید
    blocks/                نمایش هر کادر + قاب مشترک + متن غنی
    anim/                  رندر صحنه، خط زمان، بازرس‌ها
    bank/                  ویرایشگر برچسب، انتخابگر پرسش، درخت
    editor/                ویرایشگر هر نوع کادر + کارت کادر
    dnd/Sortable.ts        حسگرها، دستگیره، شبکهٔ قابل مرتب‌سازی
  pages/                   Create · View · Bank · Studio
```

**قالب‌بندی:** همه‌چیز از متغیرهای CSS در `src/index.css` رنگ می‌گیرد
(`--bg`, `--elev`, `--ink`, `--brand`, `--scene`, …) و تم‌های روشن/کاغذی/تیره
فقط همین متغیرها را بازنویسی می‌کنند. به این ترتیب هر کادر خودش را با تم هماهنگ
می‌کند — چیزی که در نسخهٔ قبلی اشتباه بود و کادرها در تم تیره هم روشن می‌ماندند.

**داده:** همه‌چیز در `localStorage`. کلیدها نسخه‌دارند
(`smart-teach:presentations:v2`). داده‌های نسخهٔ ۱ هنگام اولین اجرا مهاجرت
می‌خورند: کادرها شناسه و عرض می‌گیرند و انواع ناشناخته به متن تبدیل می‌شوند.
برای پشتیبان‌گیری کافی است از دکمهٔ «خروجی» استفاده کنید.

**فونت:** وزیرمتن به‌صورت محلی (`public/fonts/`) — کلاس معمولاً بدون
اینترنت برگزار می‌شود و نباید متن فارسی وسط ارائه دوباره چیدمان شود.

## درس آمادهٔ حرکت‌شناسی

دکمهٔ «درس آمادهٔ حرکت‌شناسی» در استودیو (یا `Ctrl/⌘ + K` → «درس کامل حرکت‌شناسی»)
یک ارائهٔ **۱۹ بخشی** می‌سازد که از روی جزوهٔ درس ساخته شده و **۱۲ انیمیشن**
دارد. متن درس بر پایهٔ همان جزوه است، ولی هر شکلِ کاغذی با یک صحنهٔ زنده جایگزین
شده است:

| بخش | انیمیشن | چه چیزی را نشان می‌دهد |
| --- | --- | --- |
| مکان و بردار مکان | عبور از مبدأ | علامت مکان عوض می‌شود |
| جابه‌جایی در برابر مسافت | $x$ از $۶$ به $-۴$ | مثال خودِ جزوه: $\Delta x = -۱۰$ ولی $s = ۱۶$ |
| شیب نمودار، سرعت است | $x = ۳t$ | خط قاطع (سرعت متوسط) کنار خط مماس (سرعت لحظه‌ای) |
| شتاب | رفت‌وبرگشت با $a < 0$ ثابت | کندشونده، سپس تندشونده — با بردار $v$ و $a$ |
| علامت کمیات | $x = -t^2 + ۶t$ | مکان مثبت ولی سرعت منفی |
| حرکت یکنواخت | $x = ۴t - ۶$ | خط راست با شیب ثابت |
| شتاب ثابت | $x = t^2 + ۳t - ۵$ | سهمی و تغییر شیب |
| مشتق | $y = t^2$ با نقطهٔ تماس | خط مماس با شیب برابر سرعت |
| سطح زیر نمودار | $v = ۲t$ با ناحیهٔ پرشده | رشد سطح = رشد جابه‌جایی |
| مکان، سرعت و شتاب در یک نگاه | چهار پنل با یک ساعت مشترک | $x(t)$ و $v(t)$ و $a(t)$ زیر هم، با خودرو در راهرو |
| شتاب در مسیر خمیده | مارپیچ با تجزیهٔ $a = a_t + a_n$ | تغییر اندازهٔ سرعت در برابر تغییر جهت |
| از متوسط تا لحظه‌ای | $\Delta t$ که خودش کوچک می‌شود | شیب قاطع روی شیب مماس می‌افتد |

برای دیدن صحنهٔ کامل، کادر انیمیشن را **تمام‌صفحه** کنید
(`Space` پخش/مکث، کشیدن روی صحنه = جابه‌جایی دستی زمان).

## ساخت ارائه با هوش مصنوعی

قالب JSON ارائه در [`docs/authoring.md`](docs/authoring.md) مستند شده است:
قواعد کلی، اسکلت ارائه و بخش، جدول همهٔ کادرها با میدان‌هایشان، زبان
فرمول انیمیشن (`expr`)، قواعد قاب‌بندی نمودار، ساختار پیشنهادی یک درس،
چک‌لیست پیش از تحویل، و یک نمونهٔ کامل که مستقیم وارد می‌شود.

مرجع کامل — همهٔ میدان‌ها، همهٔ مقدارهای مجاز، جدول اعتبارسنجی میدان‌به‌میدان،
رفتار مهاجرت، API برنامه‌نویسی، خطاها و حدود — در
[`docs/api.md`](docs/api.md) است.

کافی است یکی از این دو فایل را به یک مدل زبانی بدهید و خروجی را با
«ورودی JSON…» وارد کنید.

## استودیو: ضبط، نمودارهای روی هم، بردارها

سه چیزی که ساختن انیمیشن‌های فیزیک را از «وقت‌گیر» به «سریع» تبدیل می‌کند:

**۱. حالت ضبط (`R`).** جسم را **بکشید و رها کنید**؛ هر بار رها کردن یک
کی‌فریم در ثانیهٔ فعلی می‌نویسد و ساعت یک ضرب جلو می‌رود. نه فرمولی لازم
است، نه دستکاریِ دستی خط زمان: ترتیب کی‌فریم‌ها = ترتیب حرکت‌های شما.
دکمه‌های «ثبت وضعیت همهٔ اجسام» و «ضرب بعدی» هم هستند.

**۲. نمودارهای روی هم (`scene.panels`).** برای x(t)، v(t) و a(t) کنار هم یک
صحنه با چند پنل بسازید؛ همهٔ پنل‌ها **یک ساعت** دارند و خط عمودی راهنما
در هر سه پنل کشیده می‌شود، پس مقایسهٔ عمودی معنی دارد.

**۳. بردارها بدون دردسر.** `positionVector` پیکان مکان را از مبدأ تا جسم
می‌کشد (زاویه‌اش خودکار است، پس آینه‌ای زیر محور نمی‌افتد)؛
`vectors.decomposition` شتاب را به $a_t$ و $a_n$ می‌شکند — تغییر اندازهٔ
سرعت در برابر تغییر جهت. و `series.window` پنجرهٔ میانگین $\Delta t$ را
می‌کشد؛ اگر رشته باشد فرمولی از $t$ است، پس می‌تواند حین پخش کوچک شود تا
قاطع روی مماس بیفتد: سرعت متوسط ← سرعت لحظه‌ای.

## دسترس‌پذیری

* هر کنترل برچسب فارسی صریح دارد (`aria-label`)، و آیکن‌ها تزئینی‌اند.
* رنگ تنها حامل معنا نیست؛ پرسش درست هم سبز می‌شود هم `✓` می‌گیرد.
* حلقهٔ فوکوس در سراسر برنامه یکدست است و در تم تیره هم دیده می‌شود.
* منوها، مودال‌ها و انتخابگرها با کلید کامل کار می‌کنند و فوکوس را درست
  برمی‌گردانند؛ مودال‌ها هنگام باز بودن میان‌برهای صفحه را متوقف می‌کنند.
* پرش به محتوا در ابتدای صفحهٔ ویرایشگر هست.
* `prefers-reduced-motion` رعایت می‌شود.
* حالت چاپ، برنامهٔ درس را بدون رابط کاربری و با همهٔ کادرها می‌دهد.

## میان‌برهای تست

پروژه اسکریپت تست ندارد؛ بررسی دستی با `npm run dev` و کلید `?` کافی است.
`npm run lint` و `tsc -b` (که در `build` اجرا می‌شود) باید بی‌صدا باشند.
